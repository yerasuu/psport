psport v0.1.0

First version of psport as an independent project: a PS4 compatibility layer for x86-64 Linux,
derived from bbport 0.51 (`3c57da4`, merged as `884d0ea`) and shadPS4's video core (`b4e7ae7`,
`gpu/VENDOR.txt`), with bbport 0.6-pre1 (`72e5c8c`) changes ported by hand (`FORK.md`).

Version and launch interface
- `VERSION` is the one version source (`build.sh`, `packaging/port.nix`, `gpu/net/CMakeLists.txt`);
  a release `X.Y.Z` builds only with `tag-changelog/vX.Y.Z.md`.
- Interface this version fixes: `run.sh` variables (`PS_*`), `psport.ini` keys, launcher queries
  (`--check-game`, `--has-presets`, `--list-patches`, `--list-mods`, `--list-quirks`,
  `--list-features`, `--list-traits`, `--list-effects`, `--online-overrides`), the data folder
  layout (`PS_DATA_DIR`: `out/`, `user/`, `psport.ini`).
- `BB_*` variables copied to unset `PS_*` names with one deprecation line (`build.sh`, `run.sh`,
  `src/main/main.c`); `bbport.ini` copied once to `psport.ini`.

Loader (`src/loader/`)
- SELF/ELF eboot and linked modules read from the game folder (`loader_self.c`), laid out,
  relocated and bound into one image (`loader_link.c`); only a segment's permission bits become
  its protection.
- Modules a title loads itself (`sceKernelLoadStartModule`) linked at start, unstarted;
  `sceKernelDlsym` by name.
- `PS_SYS_MODULES`, `PS_HLE`, `PS_LLE`: optional user dump of system modules; IPMI clients never
  linked (`Loader: system module ... not linked`).
- Loose-file mods (`loader_mods.c`), shadPS4/GoldHEN XML patches (`loader_patches.c`,
  `loader_xml.c`), middleware traits `unity`, `mono`, `unreal`, `fmod`, `wwise`, `havok`
  (`loader_traits.c`, `--list-traits`).

Kernel and runtime (`src/kernel/`, `src/runtime/`)
- Direct and flexible memory, memory pools (`runtime_mempool.c`), threads, mutexes, semaphores,
  event flags, rwlocks, barriers, AIO, user-level threads (`runtime_ult.c`), exceptions.
- Thread records below 40 bits (`runtime_thread.c` `allocate_low_record`).
- Call report: every unimplemented, stub, failed and polled-status import logged once and counted;
  exit summary `Calls: summary: ...`, `PS_CALL_REPORT=<file>`; `PS_PERMISSIVE=1`,
  `PS_PERMISSIVE_OUT=error`.
- `psport.ini` read once (`runtime_config.c`); environment through `runtime_env*`.

Platform layer (`src/platform/`)
- `ps_host_*` C ABI (`ps_host.h`, decision #540), Linux in `src/platform/linux/`: time, rand,
  path, thread, fs, vm, net, fault, interrupt, proc, dl.
- Capability table `host_features.inc` (18 features); `psport --list-features` prints it as JSON;
  launch log `Host features: linux, N implemented, ...`; dma-buf and host-import probes reported.

System libraries, HLE (`src/system/`, `src/audio/`, `gpu/`)
- Services, savedata, PlayGo, content, IME and IME keyboard, NP offline, trophies with TRP packs and
  per-user unlocks in `user/trophy/<NP comm id>/` (`runtime_trophy*.c`).
- libSceNgs2 (`gpu/ngs2/`), libSceAudiodec (`gpu/audiodec/`), libSceFiber (`gpu/fiber/`),
  libSceFont/FontFt (`gpu/font/`, `PS_SYS_FONTS`, host Noto fallback), PngEnc/PngDec, Audio3d
  (`runtime_audio3d.c`), AvPlayer and Videodec2 from shadPS4.
- libSceUsbd: emulated LEGO Dimensions toy pad (`runtime_toypad.c`), off unless `PS_TOYPAD=1` or
  `toypad=1`; figures in `<user>/toypad/figures.txt`.

GPU (`gpu/`)
- shadPS4 video core and shader recompiler (`gpu/shadps4/`), cross-vendor Vulkan 1.3 with
  descriptor indexing and buffer device address (decision #361), features chosen by capability.
- One memory model: the game's memory used in place on every GPU; sparse arena or the layer
  memory module (`gpu/layer/`, `PS_LAYER_MEMORY`), dma-buf or host-import chunks
  (`gpu/memory/psport_guest_memory.cpp`, `PS_GUEST_MEMORY`); a driver that can do neither stops
  the launch (`Guest memory:`).
- No assertions on game data: malformed PM4 packets skipped and summed (`pm4_faults.*`),
  untranslatable shaders skipped (`Shader::TranslationError`), Vulkan init failures make
  `psport_gpu_init` fail, fallbacks counted (`LOG_ERROR_COUNTED`); device lost exits 24.
- Buffer V#s picked at run time read through BDA; `ShaderBinaryVersion` 12.
- Occlusion queries counted by Vulkan queries, scaled per pass under the upscaler
  (`vk_occlusion.*`, `OCCLUSION_QUERIES_BY_DEFAULT = true`; `PS_OCCLUSION_QUERIES=0` off).
- Upscalers `off`, `fsr3`, `fsr4`, `fsr411`, `taa`, `dlss` (`upscaler`, `PS_UPSCALER`), where a
  profile places them; DLSS through `gpu/dlss_bridge` with `DLSS_SDK_ROOT`.
- Output aspect ratios `auto`, `4:3`, `16:10`, `16:9`, `21:9`, `32:9` (`aspect_ratio`,
  `PS_ASPECT_RATIO`), default 16:9; UI edge stretch for profiles that follow.
- Texture substitution in the texture cache (`texture_substitutes.*`).
- Pipeline cache written by one writer thread, atomically, drained within 2 s at exit.
- PM4 command stream recording (`gpu/cp/`, `PS_CP_TRANSLATOR=1`), census (`PS_CP_CENSUS=1`),
  parallel recording probe (`PS_NATIVE_PROBE=1`).

Input (`src/input/`)
- Pad from SDL3 gamepads and keyboard/mouse; `key.<input>=`, `pad.<input>=` bindings with chords
  (`key.r2=Left Shift+Mouse Left`); title default layouts (`Game::Title` `sz_default_controls`).
- `key.menu=`, `pad.menu=` open the overlay besides Insert and L3+R3 (unbound by default).
- Real motion sensors through SDL3 (`runtime_pad_sensors.c`, `PS_PAD_SENSORS=0` off), fused as
  libScePad: tilt correction off by default; motion emulation `pad_motion=1`/`PS_PAD_MOTION=1`
  (`runtime_pad_motion.c`); pad at rest reports 1 g up.
- libSceMouse (`game_mouse_sensitivity` 0.05-20), libSceImeKeyboard, gestures; button prompt device
  tracking (`runtime_pad_prompt*`); `PS_PAD_FILE` scripts with `mdx=`/`mdy=`, `PS_PAD_TRACE=1`.

Game titles and profiles (`gpu/games/`)
- `Game::Title` (launch, file check, patches, quirks, effects, online overrides) and
  `Game::Profile` (optimisations); `PS_GAME_PROFILE=none` runs generic paths only.
- Guest code hook layer `PsGuestCode` (`gpu/port/psport_guest_code.*`): byte-checked hooks and
  detours.
- Bloodborne (`gpu/games/bloodborne/`): 1.09 check, frame rate by hooks (`PS_FRAME_HOOKS=0`
  falls back to patches), mouse look and menu pointer, live aspect ratio, button prompts for the
  device in use (`PS_BUTTON_PROMPTS=0` off), effect switches (`--list-effects`).

Quirks (`src/runtime/runtime_quirks.inc`, `docs/en/QUIRKS.md`)
- `HOST`: `nvidia_slow_sparse_rebind`, `radv_gcn_nohiz`, `nvidia_slow_depth_copies`.
- `WORKAROUND`: `bloodborne_save_sound_flag`, `bloodborne_gx_node_guard`.
- `PS_QUIRKS=none,-<id>,+<id>`; `psport --list-quirks [--game <dir>]`; `Quirks: N active` at exit.

Online module (`gpu/net/`, `libpsport-net.so`, `PS_ONLINE=1`)
- shadNet client reports `psport 0.1.0 (PS4 compatibility layer; shadPS4 network code)`
  (command 13, `PS_SHADNET_CLIENT_VERSION` overrides); a rejection keeps shadNet off for the
  session.
- Defaults: `PS_SHADNET_SERVER=play.seamlesshunt.com:31313` (Seamless Hunt), WebAPI port 31315.
- P2P relay fallback (`BBR1`, UDP 3478), `sceNpLookupNpId`; per-title online extensions
  (`games/<game>/net/`, `PSPORT_NET_ABI_VERSION` 3).
- BBSC (Bloodborne seamless co-op) opt-in: `PS_BBSC=1`, `PS_BBSC_LOCAL_SERVER=1|auto`.

Defaults that matter
- `PS_SUBMIT_AHEAD=0`, `PS_FRAMES_AHEAD=1`, `PS_ANISO=0`, `PS_READBACKS=1`,
  `PS_COPY_GPU_BUFFERS=1`, `PS_GPU_WRITE_TWINS=1`; `PS_DMEM_MB=9152` only for titles with presets.
- Ignored with one line: `PS_PC_MODEL`, `PS_AS_0_3`, `PS_GUEST_IN_PLACE`, `PS_PREUPLOAD`,
  `PS_UFFD`.

Launcher, packaging and tools
- GTK4 launcher (`launcher/psport-launcher.sh`, app id `io.github.psport.Launcher`).
- `packaging/port.nix` (Nix build), `tools/bundle.sh` (relocatable `psport-<tag>-x86_64.tar.zst`),
  `tools/nix_cache.sh` (binary cache in the `nix-cache` release).
- `tools/regress.sh` (14 titles in `tools/regress/titles.txt`, `-c` regressions),
  `tools/regress/report.py --compare-shots`, `tools/regress/night.sh`.
- Profiling: `PS_TRACY=ON`, `PS_PROFILE=1`, `tools/profile/perf.sh`, `compare.sh`,
  `PS_RENDERDOC_CAPTURE_FRAME=N`.
- Build: `PS_LTO` (on), `PS_PGO`, ccache in `~/.cache/psport/ccache`.
