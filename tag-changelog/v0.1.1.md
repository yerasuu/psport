psport v0.1.1

Fixes and ports on v0.1.0: bbport 0.6-pre1 and shadPS4 (`b4e7ae7..c1b2655`) changes ported by hand
(`FORK.md`, `gpu/VENDOR.txt`), firmware behaviour read with REA for kernel, system and video
libraries, keyboard/mouse and glyph support for more titles. No change to the launch interface.
The Windows platform layer is not part of this version beyond its groundwork (`ps_host_*`
refactors, `src/platform/win32/` basic calls, `EXPERIMENTAL` in `host_features.inc`).

Packaging and licence
- Bundle and Nix cache ship without the online module (`libpsport-net.so`: OpenSSL, abseil) until
  its mbedTLS port (#850); the bundle carries `THIRD-PARTY-NOTICES` and the source offer, FFmpeg
  builds as LGPL without network; `tools/check_bundle_licences.sh` gates release and cache publication.
- `--list-features`: `online_module` reports unavailable when `libpsport-net.so` is missing.
- AnyPS5-derived Ngs2 and Audiodec code and four shadPS4 files carrying rpcs3 code marked
  `GPL-2.0-only` in their SPDX headers; unused GPL v2 `endian.h` dropped.
- README state tables say playable, experimental, broken or not supported; per-title detail moves
  to `docs/en/GAMES.md`, `docs/es/GAMES.md`, `docs/ru/GAMES.md`; Spanish and Russian READMEs synced.
- Python in the package without build configuration, IDLE, tkinter and tests, bytecode kept
  (closure 678 to 602 MiB).
- `build.sh` keeps compiler temporaries in `out/tmp` and empties it; `run.sh` keeps the newest 30
  saved runs (`PS_KEEP_LOGS`).
- Branch commits published to the Nix cache as `commit-<sha>`, newest 20 kept (`tools/nix_cache.sh`).

Launch, settings and diagnostics
- `PS_CACHE_DIR` roots the shader and pipeline caches and the drivers' caches (`MESA_SHADER_CACHE_DIR`).
- `PS_DEBUG=1` / `debug=1` gathers run.log, gpu.log, calls, faults, validation, frame stats, env, config
  and summary in `<PS_DEBUG_DIR>/<host>/<time>-<serial>/`; `.partial` renamed when complete,
  `summary.txt` last; newest `PS_DEBUG_KEEP` kept.
- `PS_FAULT_DUMP` prints named guest ranges after the fault line; `runtime_memory_read_guest` falls
  back to the backing view for dma-buf ranges (`runtime_memory_read_backing`).
- `psport --list-controls [--game dir | --title TITLE_ID]`: neutral layout with the title's
  `sz_default_controls` over it; `--list-features` reports upscalers and the Intel tone mapping fix;
  `key_stick` row names `key_stick_opposite`, `key_stick_hold_ms`.
- `--gpus` keeps the GPU by name (PCI address for same-name GPUs); the game's 21 text languages;
  a repeated ini key is not copied on save; an HTTP status below 500 counts as a reachable server.
- Fixes: `run.sh` quit silently at even output sizes on native preset (`set -e` with `(( ))`);
  `live_resolution` read as psport does (`atoi`, clamped 0..1); HOME unset no longer segfaults
  `libpsport-gpu.so`; stop of the process group keeps the saved log (quit line, calls summary);
  the whole exit report prints on a window close (locks wait at most 100 ms).
- Default user name `Player` (`PS_USER_NAME` overrides); saves and trophies key off the user id.
- Overlay menu scrolls within the screen; checkbox and slider changes kept under Clang.
- `PS_DUMP_SMALL_TEXTURES` lists small textures per XXH3 (`index.tsv`, PNG of level 0);
  `tools/regress/small-textures.plan`.
- `tools/regress/plan.sh`: night plans resumed after a cut, time window, online off in every step.

Loader (`src/loader/`)
- Mod folders accepted with a suffixless README, a second wrapper or a `Screenshots` folder; each
  rejected folder logged with its reason.
- An external patch over a profile patch's bytes removes the profile patch whole, logged; titles may
  refuse external patches.
- Patched `fs:[0]` loads use `ps_host_tls_tcb_offset` (0 on Linux) and match `mov r64` for all 16 registers.

Kernel and runtime (`src/kernel/`, `src/runtime/`)
- Mutexes follow libthr: unlock by a non-owner `EPERM` for every type; condition waits release every
  hold of a recursive mutex; timed lock by the owner sleeps the timeout, `ETIMEDOUT`; adaptive
  owner try lock `EINVAL`; recursion overflow `EAGAIN`; failures counted; `pthread_mutex_timedlock`.
- `scePthreadRwlockTimed{rd,wr}lock` take a relative uint32 timeout in microseconds.
- libSceUlt sync objects native: mutex, condvar, rwlock, semaphore, queue, both pools, Finalize,
  TryJoin, GetSelf, Yield, Exit; one host thread per ulthread, holding a worker slot released while waiting.
- libkernel: vectored and synced I/O, pipes, dup, flock, cwd, signals, rlimits, kqueue
  read/write/vnode filters, OpenEventFlag, attribute getters; unknown sysctl MIB is a counted `ENOENT`.
- Rtc: `TickAdd*` wrap as the firmware does; `AddMonths`/`AddYears` return 0 out of 1..9999;
  `SetCurrentTick` and network clocks kept as offsets in the process.
- Time zone: `sceKernelGettimezone` returns standard offset east plus DST minutes; each tick converted
  with the rule of its instant (dst_sec may be negative); system params 4/5 split zone and summer time.
- `runtime_socket.c`: `sceNetInetPton`/`PtonEx`/`Ntop` as the firmware; `sceNetInit`, net pools
  (ids `3000+slot`) and SSL contexts (1..128) implemented; `sceNetEpollAbort` wakes waiters through
  an eventfd per epoll, `EINTR` (0x80410104) counted as status; `sceHttpGetStatusCode` `EAGAIN`
  (0x80431082) counted as a polled status.
- `ps_host_vm_*` carry guest map, low allocator, direct memory memfd, dma-buf probes, trap tables and
  code patching (`ps_host_vm_keep_heap_low`); guest thread pointer through `ps_host`.
- Win32 `ps_host` basic calls (time, rand, path, dl, thread), mingw-w64 compile-checked, `EXPERIMENTAL`;
  `ps_host_fault_recover` takes `PsHostRecoveryPoint`.

System libraries and audio (`src/system/`, `gpu/`)
- `sceMsgDialogOpen` reports RUNNING until answered; without a window or with `PS_MSGDIALOG_AUTO_MS`
  the default button is chosen after a delay.
- IME text typed with a keyboard grid driven by the pad (max length, IME type); name dialog accepted
  by Cross, Circle cancels, empty field starts with the user's name, held buttons withheld until released.
- JpegDec over FFmpeg's MJPEG, LoginDialog, `sceImeFilterText`, UserService priority and Initialize2,
  PngDec/JpegDec checks, Font attributes, Ajm batches per context, AudioIn `GetGain`/`GetRerouteCount`,
  Sysmodule internal unload, SaveData argument errors (kb #696).
- libSceVoice port info: no table before `sceVoiceStart` (0x804E080A), ids past 63 `0x804E0804`.
- SystemGesture primitive touch events: 8 tagged handles, `0x8089` errors, 200 ms gap, bit 31 cancel.
- Ngs2 mastering voice enables the LFE low-pass at 120 Hz and the limiter (unit 0x11); `0x30000003`
  sets enable and threshold clamped to [0,4]; OpenOrbis hardware test for it.
- 7.1 downmix to a stereo device with fronts at unity (SDL's matrix plays them at 0.2119).
- AvPlayer as retail: no event at end of file, `CurrentTime` from the last video frame, sample-table
  timestamps without edit list media time, Stop/Start after EOF by the compiled SDK version
  (one `StateStop`, later no-ops from 5.50, `JumpToTime` only while playing or paused); frames follow
  an unbounded clock when the video has no audio.
- Limited flips paced from the planned slot (sleep, then spin).
- `skip_movies=1` / `PS_SKIP_MOVIES=1`: `key.skip_movie` (Escape), `pad.skip_movie` (misc1).

GPU (`gpu/`)
- Recompiler backports from shadPS4 `b4e7ae7..c1b2655`: NaN and `DX10_CLAMP`, wave64 ballot/MBCNT,
  LDS subgroup barriers, unbiased indirect draw ids, early fragment tests, CFG fixes, `OpNClamp` in
  sirit; `ShaderBinaryVersion` 14 (cached shaders rebuilt).
- Texture cache and copy backports (17 shadPS4 commits in `gpu/VENDOR.txt`): overlaps keep GPU data,
  CMask reads decompress, mip/layer and D32<->D32S8 copies, stencil-only targets, fallbacks for bad S#
  and empty index buffers; liverpool: nested IB tasks freed, CE/DE wait underflow guarded, ASC ring offset reset on map.
- Slot vector entries in fixed chunks; `ForEachItemBelow` and `ForEachPage` stop when the callback
  returns true (the 256-image cap of `GarbageCollectImages` now applies).
- `MarkAsMaybeDirty` and `RefreshImage` hash the same range; texture GC pressure at least 60 % below
  8 GB (`PS_GC_PRESSURE_PERCENT`, 10-75), capped at 30 % of the budget by the bbport 0.6 port; collector
  backs off 32..1024 submissions when it frees nothing.
- Under 1 GiB of device-local memory with a shared heap, never-rendered images prefer the shared heap.
- Tiling into VRAM before one copy to system memory (`PsToggle::LocalTiling` off); full VRAM waits for
  submitted work, frees empty buffer cache chunks and retries.
- Swapchain recreated under `submit_mutex`; presenter frame semaphore waited at Transfer; draw push
  constants recorded after the pass begins.
- Depth targets sized by the slices a draw writes (`DB_DEPTH_VIEW.slice_max` is not an array size).
- Asserts replaced by counted fallbacks in pipeline cache, rasterizer, buffer cache, upscaler images,
  GNM and VideoOut misuse; stubbed gnmdriver calls added (`DrawIndirectCountMulti`,
  `RequestFlipAndSubmitDone`, `ComputeWaitSemaphore`, `SetGsRingSizes`).
- SRT walker faults supply zero through the platform layer instead of patching code; the faulting
  table is named once per (shader, table) with a count by table at exit.
- Shader control flow: `V_CMPX` block without false branch, merge blocks past a break and Phis over
  register operands no longer throw out of the Liverpool task.
- Object motion positions stored without atomics (`OpAtomicExchange` through `PhysicalStorageBuffer`
  lost the device on RDNA2); `VK_EXT_device_fault` report at device lost.
- Upscaler history reset on camera cuts; reactive mask in GENERAL; psport's Vulkan images named.
- Shader specialization reused between matching draws (Bloodborne 304 of 418 lookups per frame).
- Unhandled image metadata warning capped at 8.

Input (`src/input/`)
- Short pad presses latched between reads and dropped after 100 ms; keyboard stick: last key wins,
  60 ms hold, no read turns over 30 degrees; View + d-pad left/right clicks the touchpad halves.
- `PS_PAD_REPLAY` route read at every start.
- Black Ops 1 and 2: shooter layout from `buttons_default.cfg`, mouse camera through `CL_MouseMove`
  accumulators, crosshair held on with keyboard; look gain, smoothing and deadzone as ini keys a title sets.
- Button glyphs as data (`gpu/games/common/glyphs.h`, shape, format and hash): Bloodborne's 22 `KG_*`
  icons, Atelier Ayesha DX from one 512x512 BC3 atlas (`Atlas::is_upside_down`).

Titles and quirks (`gpu/games/`, `src/runtime/runtime_quirks.inc`)
- `WORKAROUND` quirks added: `bloodborne_gx_command_heap`, `bloodborne_render_job_slots`,
  `bloodborne_blur_sample_clamp`, `bloodborne_fx_init_clear`, `bloodborne_intel_tonemap`
  (`PS_INTEL_TONEMAP_FIX=0/1` forces it); `bloodborne_gx_node_guard` logs the GX swap chain at null nodes;
  Disable Bloom as an effect switch.
- Bloodborne: profile sets `PS_DMEM_MB=9152` unless given; play time counted by real time; replay ghosts
  stepped by frame time; dead physics step write at `0x011383CA` dropped (`0x01BF9B74` stays hooked);
  external FPS patches refused before the pacer sites are checked.
- Bloodborne online code moved to `gpu/games/bloodborne/net/summon_client.cpp`; BBSC kit given to new
  characters only with a verified save backup; param tables from `SoloParamRepository` (63 slots).
- Octopath 0: unhandled CMask metadata left as is; Blood Omen 2 and Gal Guardians 2 shader and depth fixes.

Not in this version
- Windows port (not integrated), online module in the bundle and cache (#850).
